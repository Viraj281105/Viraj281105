## 🛠️ DEEP TECHNICAL SPECIFICATIONS & SYSTEM TUNING

To ensure our AI and backend systems perform at enterprise scale under high concurrent load, we apply the following kernel, database, and JVM tuning configurations:

### 1. Vector Database Optimization (PostgreSQL + `pgvector`)
We tune the query planner and indexing strategies in our PostgreSQL instances to balance recall accuracy and query latency:
*   **HNSW Index Configuration:**
    ```sql
    -- Custom index setup for high-speed IndicSBERT embedding matching (768 dimensions)
    CREATE INDEX ON medical_claims_embeddings 
    USING hnsw (embedding vector_cosine_ops) 
    WITH (m = 16, ef_construction = 64);
    ```
*   **Query Memory Allocations:**
    ```ini
    # postgresql.conf Custom Tuning Profile
    shared_buffers = 4GB                # 25% of system memory
    work_mem = 64MB                     # Higher threshold for sorting & vector indexing operations
    maintenance_work_mem = 512MB        # Accelerated index construction
    effective_cache_size = 12GB
    ```

### 2. High-Throughput FastAPI Server Configuration
FastAPI services are deployed via Gunicorn with Uvicorn workers to maximize concurrent connections under asyncio:
*   **Process Supervisor Settings:**
    ```bash
    # Production deployment supervisor command
    gunicorn main:app \
      --workers 4 \
      --worker-class uvicorn.workers.UvicornWorker \
      --bind 0.0.0.0:8000 \
      --timeout 120 \
      --keep-alive 5
    ```

## 🗺️ Engineering Philosophy & System Execution Rules

```
┌────────────────────────────────────────────────────────────────────────┐
│               SYSTEM DESIGN RUNTIME PARAMETERS                         │
├────────────────────────────────────────────────────────────────────────┤
│ RULE 01: Avoid monolithic dependencies. Design decoupling interfaces.  │
│ RULE 02: Trust calibration over raw LLM output. Verify every token.    │
│ RULE 03: Run computations close to the source. Quantize edge models.   │
│ RULE 04: Restructure workflows as state-machines to recover gracefully.│
└────────────────────────────────────────────────────────────────────────┘
```

1.  **Build Resilient State-Machines, Not Prompts:** Prompt engineering is insufficient for production. Complex workflows must be modeled as state-graphs with explicit cycles, error handlers, and transactional rollbacks.
2.  **Strict Schema Isolation:** Microservices should never share databases. If the Agentic service needs user metrics, it fetches them via REST/gRPC endpoints exposed by the Core Account service, preserving clear bounds.
3.  **Validate All Generated Assets:** AI output must be treated as untrusted user input. Whether code, SQL query, or summary text, run AST parsing, containment checkers, or entailment calibration before serving.
